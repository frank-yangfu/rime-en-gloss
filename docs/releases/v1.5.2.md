# v1.5.2 — 二字母五笔短码优先（wu → 们）

发布日期：2026-10-29

## 症状

输入 `wu` 出现「无」，而不是五笔二级简码「们」。同理 `de` 出「的」而不是「胡」，
`wo` 出「我」而不是「伙」，`ni` 出「你」而不是「悄」。

## 原因

二字母编码（wu/ni/de/wo…）同时是**合法拼音音节**和**五笔二级简码**。v1.5.1 之前
统一按拼音处理，所以五笔短码候选被隐藏。

## 修复

v1.5.2 对二字母输入启用**短码混排**：先列前 3 个五笔候选，再跟拼音候选。

| 输入 | 现在（前 6 项） |
|---|---|
| `wu` | 们 / 位置 / 伴侣 / 无 / 五 / 吴 |
| `ni` | 悄 / 尿 / 恍 / 你 / 里 / 李 |
| `de` | 胡 / 有效 / 有 / 的 / 得 / 地 |
| `wo` | 伙 / 偻 / 侎 / 我 / 喔 / 窝 |

- 单字母仍是一级简码优先（`o`→为）；
- 三字母及以上不变（`shi`→是）；
- 词码混排、147k 扩展词库、`wubi_override.txt` 均不变。

## 升级

只需替换 `lua/input_text.lua` 并重启/重新部署；词典不变（仍用 v1.5.0 附件）。

## 说明

二字母歧义不可避免：五笔用户看到五笔候选在前，拼音用户在第 4 项就能选到拼音；
如果想让某一边完全独占，可以把它加进 `lua/wubi_override.txt`（强制五笔）或改回拼音模式。
