# v1.4.0 — 五笔常用词补全（骑行 cdtf / 车店 lgyh）

发布日期：2026-10-29

## 症状

五笔码明明“应该是”某个常见词，却打不出来：

- 输入 `cdtf` 得到「参选」，想打的是「骑行」；
- 输入 `lgyh` 什么都不出（或只出单字），想打的是「车店」；
- 类似：`ymqr` → 高铁（旧词库没有）。

根因不在拼音/分栏逻辑，而是 **wubi86 基础词库本身缺词**：`cdtf` 只有「参选/参赞」，
`lgyh` 一条词条都没有。词库来自老版 ibus-table，现代常用词覆盖不足。

## 新增

### 1. 五笔常用词补全词典（Release 附件）

- `wubi86.extended.dict.yaml`：约 **68,000** 条补充词条，导入基础 `wubi86` 词库；
- 覆盖 2–4 字常用词/词组，权重按现代语料频率分档；
- 修复示例：`骑行 → cdtf`、`车店 → lgyh`、`高铁 → ymqr`；
- 用法：
  1. 下载附件，放到 Rime 用户目录（与 `wubi86.dict.yaml` 同目录）；
  2. 在方案的 `.custom.yaml` 里 patch：
     ```yaml
     patch:
       translator/dictionary: wubi86.extended
     ```
  3. 重新部署。

### 2. `tools/build_wubi_words.py`

从任意中文词表生成上述补全词典：

```bash
python tools/build_wubi_words.py \
    --wubi-dict "%APPDATA%\Rime\wubi86.dict.yaml" \
    --words words.txt \
    --extra data/wubi_words_extra.txt \
    --out "%APPDATA%\Rime\wubi86.extended.dict.yaml"
```

- 自动按 AaAbBaBb / AaBaCaCb / AaBaCaZa 计算五笔词码；
- 空码词给低权重（可见、不干扰），弱码词给 `--floor`，强码保持原顺序；
- 支持 `--weights-file` 传入自己的 `词<TAB>权重` 频率表；
- `--extra` 可保留手写词条（人名、个人词汇），重跑不丢。

### 3. 文档：`docs/wubi-words.md`

包含原理、生成方法、个人词条添加、以及**拼音只认全拼**的推荐配置
（从 `pinyin_simp.custom.yaml` 的 `speller/algebra` 里移除 `pinyin:/abbreviation`，
避免简拼缩写和五笔码混淆）。

## 升级

- lua 插件、`wubi_override.txt`、释义 `cache.txt` **均无变化**，无需替换；
- 新增的 `wubi86.extended.dict.yaml` 是可选的（不装仍然可用，只是缺词依旧）；
- 词典/方案 YAML 改动需要重新部署（lua 改动仍只需重启服务）。

## 已知限制

- 补全的是“词典里能查到的常用词”；任意新造组合（如某些店名）不一定有，
  可以用 `--extra` 或直接往 `wubi86.extended.dict.yaml` 加一行 `词 编码 权重`。
- 权重采用启发式：弱码让补全词领先，强码保持原基础词库排序（避免喧宾夺主）。
- 与 v1.3.2 的 `wubi_override.txt` 白名单独立：一个管“码归谁”，一个管“词有没有”。
