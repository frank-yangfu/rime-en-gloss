## rime-en-gloss v1.0.0

在 Rime 输入法（小狼毫 / 鼠须管 / ibus-rime / fcitx5-rime）的**候选栏里实时显示英文**：
输入中文，候选右侧就带上对应的英文释义。纯离线，不需要任何 API key。

![候选栏效果](../images/candidate-english.png)

```
┌─────────────────────────────────────┐
│ wjjg                                │
├─────────────────────────────────────┤
│ 1. 告诉    wjjg, to tell; to inform │
│ 2. 东西    aiit, thing; stuff       │
│ 3. 结果    xfjs, result; outcome    │
└─────────────────────────────────────┘
```

### 亮点

- **纯离线**：数据来自 CC-CEDICT + 人工校准表，不联网、不用密钥、不依赖任何翻译服务
- **只挂 filter，不影响选词**：空格上屏的永远是中文，英文只在注释槽里
- **不卡输入法**：只在缓存未命中时读盘、单次解析 ≤ 4 万行、只处理前 30 个候选、绝不在输入线程里起进程
- **格式统一**：`编码, 英文`

### 安装（3 步）

```bash
git clone https://github.com/frank-yangfu/rime-en-gloss.git
cd rime-en-gloss

# 1) 插件
cp lua/input_text.lua  <Rime 用户目录>/lua/
#    小狼毫 %APPDATA%\Rime\lua   /  鼠须管 ~/Library/Rime/lua

# 2) 词表（二选一）
#    a. 自己构建：python tools/fetch_cedict.py && python tools/build_cache.py
#    b. 直接用本 Release 的 cache.txt 附件（见下）

# 3) 挂到方案：把下面存成 <方案>.custom.yaml，然后重新部署
#    patch:
#      "engine/filters/+":
#        - lua_filter@*input_text*filter
```

Windows 上有一次性脚本：`powershell -ExecutionPolicy Bypass -File scripts\install.ps1`

### 译义质量

这一版的译义经过两轮全量审查，修掉的问题包括：

| 问题 | 例子 |
|---|---|
| 词典首条义项是冷僻义 | `告诉 → to press charges` 改为 `to tell; to inform` |
| 多音词条顺序取错 | `打 → dozen` 改为 `to hit; to play`；`一次 → first` 改为 `once; one time` |
| 自引用空壳词条吃掉 244 个常用字 | `妙 吻 埋 借 凡 仙 农 丐 匙 凳 …` 原本没有英文，现已恢复 |
| 专有名词义项抢占 | `比萨 → Pisa` 改回 `pizza`；`大拇指 → Tom Thumb` 改回 `thumb` |
| 机器翻译垃圾条目 | `人不 → No, no, no`、`就能 → Yeah` 全部剔除（模型只允许处理 3 字以上的词）|

细节见 [docs/quality-review.md](../quality-review.md)，
回归防护见 `tools/selftest.py`（CI 每次提交都会跑）。
