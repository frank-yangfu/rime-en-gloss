# v1.3.0 — 五笔/拼音候选分离

发布日期：2026-10-21

## 新增：打五笔只出五笔候选，打拼音只出拼音候选

在此之前，同一个输入串会同时查五笔和拼音两张表，候选混在一起：
打拼音 `tangping` 会出现五笔硬拼的「彻悟这渥」，打五笔 `trnt` 会出现拼音的「瘫软了」。

现在按输入串自动切换：

| 输入 | 结果 |
|---|---|
| 五笔 `wqiy` | 你、仰泳 |
| 五笔 `sn` | 杨、札、杞 |
| 五笔 `trnt` | 我、特性 |
| 拼音 `nihao` | 你好、利好 |
| 拼音 `tangping` | 躺平、烫平 |
| 拼音 `yuanyuzhou` | 元宇宙 |

### 实现原理

librime 给每个候选标注 `type`，它揭示了候选来自哪个翻译器：

| type | 来源 |
|---|---|
| `table` | 五笔单字/词 |
| `completion` | 五笔补全 |
| `phrase` | 拼音词组 |
| `sentence` / `reverse_lookup` | 组句 / 反查噪声，一律丢弃 |

输入模式判定：输入串能**完整切分**为合法拼音音节 → 拼音模式；否则若存在五笔 table
候选 → 五笔模式。内置 421 个拼音音节表，带记忆化回溯切分。

## 修复的噪声

- **五笔组句**（`translator/enable_sentence: false`）：消除 `tangping -> 彻悟这渥`
  这类把拼音码硬拼成句子的候选。
- **反查翻译器**：它经 `abc_segmentor/extra_tags` 对所有输入生效，产出 quality=0
  的无意义候选，已移除。

## 升级

替换 `lua/input_text.lua`，并在方案补丁里加上：

```yaml
patch:
  translator/enable_sentence: false
  pinyin_input/initial_quality: -10
```

并删除 `engine/translators` 里的 `reverse_lookup_translator`（可选，见 CHANGELOG）。

## 已知取舍

- 1~2 个字母的输入同时可能是五笔简码和拼音音节（`a`、`an`、`ai` 等），
  这类短码按候选集合判断：有五笔 table 候选时按五笔处理。
- 移除反查翻译器后，方案里的「反引号拼音反查」不再可用；需要时可以把
  `reverse_lookup_translator` 加回去，但噪声也会回来。
