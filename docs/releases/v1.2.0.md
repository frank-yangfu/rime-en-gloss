# v1.2.0 — 英文释义质量修复（俚语降权 + 长释义救回 + 中性化）

发布日期：2026-10-20

## 修复一：俚语义项抢占常用义（选义算法缺陷）

CC-CEDICT 里很多词带俚语义项，而这些义项**又短、又由常用词构成**，
`_score()` 的打分反而给它们高分，于是屏幕上显示的不是你想要的释义：

| 词 | 修复前 | 修复后 |
|---|---|---|
| 草 | to fuck | **grass** |
| 巨龙 | big dick | **giant dragon** |
| 鸡年 | Year of the Cock | **Year of the Rooster** |
| 公鸡 | cock; rooster | **rooster** |
| 滚开 | get out; go away; fuck off | **get out; go away** |
| 杂种 | son of a bitch | **hybrid** |
| 种禽 | cock | **breeding poultry** |
| 杨 | alder tree | **poplar; surname** |

**修法**：新增 `VULGAR_DEF` 俚语词表 + `_vulgar_penalty()` 降权 ——
**降权而非删除**：词本义就是俚语的仍保留原义，保证诚实。

## 修复二：超长释义被整条丢弃

`best_gloss` 对超过 40 字符且**没有分号**的释义会整条丢弃，导致知名词条取不到英文：

| 词 | 释义长度 | 修复前 | 修复后 |
|---|---|---|---|
| 一带一路 | 90 字符 | （无英文） | **Belt and Road Initiative** |
| 中国人民解放军 | 85 字符 | （无英文） | **People's Liberation Army** |

**修法**：按逗号取首段，最后按词边界兜底截断。

## 修复三：粗俗释义中性化（47 条）

保留 `(vulgar)` / `(derogatory)` 标注——词义仍然诚实，
但屏幕上不再出现脏字本身：

| 词 | 修复前 | 修复后 |
|---|---|---|
| 傻逼 | stupid cunt | **(vulgar) idiot** |
| 婊子 | whore | **(vulgar) prostitute** |
| 肏 | to fuck | **(vulgar) to have sex** |
| 干你娘 | fuck you | **(vulgar) an obscene curse** |
| 屁民 | shitizen | **(derogatory) ordinary people** |

## 新增：补词与构建工具

- 英文词表 **96,991 → 111,456 条**
- 保守剥离法：`自己的 -> oneself`、`公司的 -> company; firm`、
  `优秀的 -> outstanding`。只剥离语义等价的 `的/们/地/得`，
  不剥 `了/着/过/不/没`（会改变时态/否定语义）。
- **主动放弃**的方案：机械拼接单字释义（`自己的 -> self + self + of`）质量太差，
  宁可不显示英文，也不显示错的英文。
- `tools/build_pinyin_exp.py`：从 CC-CEDICT 构建扩充拼音词库（145,480 条）。
- `tools/build_pinyin_simp_merged.py`：三层合并（原词库 + CC-CEDICT + 万象拼音），
  产出 151 万条词库（≥5 字长词 15.9 万条）。

## 已知边界

- 约 6.5 万条 CC-CEDICT 未收录的口语组合词（如果你 / 我觉得 / 是一个）仍无英文，
  属词典覆盖边界，硬凑会误导。
- 词表读取保持分批（`MAX_LINES_PER_CALL: 40000`，实测 0.142s）：
  一次读 11 万行需 0.475s，在宿主输入线程中会造成明显卡顿，故不采用。
