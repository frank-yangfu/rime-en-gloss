# v1.5.1 — 单字母五笔优先 + 恢复短码补全

发布日期：2026-10-29

## 症状

- 输入 `o` 出现「噢」，而不是五笔一级简码「为」；
- 输入 `wq` 只出「你」，低 / 像 / 爸 / 爷 / 釜 等短码补全全没了；
- 感觉「越改越不好用」。

## 原因

1. **单字母**：过滤器把 `o` 当作拼音音节（噢/哦），先走了拼音模式，五笔的「为」被隐藏。
   这是旧规则一直存在的问题，不是这次才引入的，但 v1.5.x 的改动让它更显眼。
2. **wq 只剩你**：v1.5.0 为了压住大词库的补全噪声，推荐关闭了 `translator/enable_completion`，
   结果短码补全也一起没了——属于过度修正。
3. **shi 拼音被挤掉**：147k 词库 + 补全导致短码（1–3 字母）前面堆了几百条补全，
   拼音候选被挤出判定范围；v1.5.0 通过“关闭补全”规避，代价是你看到的短码列表消失。

## 修复

1. **单字母五笔优先**：`#input == 1` 时只要字表有候选就走五笔（`o`→为、`a`→工、`e`→有）。
2. **恢复短码补全**：`translator/enable_completion` 恢复默认开启，`wq` 重新出现完整短码列表。
3. **头部候选上限 200 → 1000**：在保留补全的同时，让 `shi` 这类拼音输入仍能进入拼音模式，
   实测 `shi` → 是 / 时 / 事 …
4. 其余（147k 扩展词库、五笔词优先混排、`wubi_override.txt`）保持不变。

## 升级

替换 `lua/input_text.lua`，并把 `wubi_pinyin.custom.yaml` 里的
`translator/enable_completion: false` 删掉（或改成 true），重新部署。
扩展词库仍用 v1.5.0 的附件（本次无变化）。

## 验证
