# v1.3.1 — 修复一级简码出错字（g 出「开」应为「一」）

发布日期：2026-10-21

## 问题

打五笔一级简码时出的是错字，例如：

- 打 `g` 首位是「开」，应该是「一」
- 打 `q` 首位是「错」，应该是「我」
- 打 `r` 首位是「找」，应该是「的」

## 原因

v1.3.0 引入了「五笔/拼音候选分离」的过滤器，它按候选的 `type` 判断来源。
漏掉了一类 type：**用户词库学到的条目**。

librime 对"词典里的"和"学进用户词库的"用不同 type 标注：

| type | 含义 |
|---|---|
| `table` / `completion` | 五笔词典 / 五笔补全 |
| `user_table` | **五笔用户词库**（你打过的字词被记住）|
| `phrase` | 拼音词典 |
| `user_phrase` | **拼音用户词库** |

当你把「一」打过几次之后，它就从 `table` 变成 `user_table`；过滤器把它丢掉，
于是首位候选变成了补全候选「开」。

## 修复

- 五笔模式接受 `table` / `completion` / **`user_table`**
- 拼音模式接受 `phrase` / **`user_phrase`**
- 单字母输入恢复查英文（`MIN_CODE_LEN` 由 2 改回 1）

## 验证

26 个一级简码全部命中正确字，且带英文注释：

```
a → 工 [a, work]      g → 一 [g, one]       m → 同 [m, same; together]
b → 了 [b, done…]     h → 上 [h, up; on…]   n → 民 [n, people; folk]
c → 以 [c, with…]     i → 不 [i, not; no]   o → 为 [o, for; to be]
d → 在 [d, at; in]    j → 是 [j, to be]     p → 这 [p, this]
e → 有 [e, to have]   k → 中 [k, middle…]   q → 我 [q, I; me]
f → 地 [f, ground…]   l → 国 [l, country]   r → 的 [r, of]
```

五笔词组（`aawt`→工作）、拼音（`tangping`→躺平）、人名（`sniagwqjh`→杨满钊）均正常。

## 升级

替换 `lua/input_text.lua` 后重启输入法服务即可（lua 改动无需重新部署）。
