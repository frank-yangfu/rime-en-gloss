rime-en-gloss

在 Rime 输入法（小狼毫 / 鼠须管 / ibus-rime / fcitx5-rime）的候选栏里 实时显示英文释义。纯离线，不需要 API key，打字不卡。

查看 GitHub 下载词表 v1.0.0

英文在候选的注释槽里 —— 按空格上屏的永远是中文，不会误选英文

三行装好

# 1) 插件（Rime 用户目录：小狼毫 %APPDATA%\Rime，鼠须管 ~/Library/Rime）
cp lua/input_text.lua  <Rime 用户目录>/lua/

# 2) 词表：自己构建，或直接下载 Release 里预生成的 cache.txt
python tools/fetch_cedict.py && python tools/build_cache.py

# 3) 挂到方案：存成 <方案>.custom.yaml，然后重新部署 Rime
patch:
  "engine/filters/+":
    - lua_filter@*input_text*filter

Windows 上也可以直接跑 scripts\install.ps1，它会自动完成上面三步。

为什么是它

纯离线数据来自 CC-CEDICT + 人工校准表，不联网、不用密钥、不依赖任何翻译服务。
不抢你的选词只挂 filter，英文写在注释槽；空格上屏的永远是中文。
不卡宿主程序只在缓存未命中时读盘、单次解析 ≤4 万行、只处理前 30 个候选，绝不在输入线程里起进程。
格式统一每一行都是 编码, 英文；单字没有编码时用你正在输入的编码兜底。
96,784 条单字 6,123、双字 55,591、三/四字 35,070，连打 3 个字即全部载入内存。
可校对、可回退人工校准表就在 tools/glossary.py，改一行重跑构建即可；自检脚本防回退。
